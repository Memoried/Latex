\chapter{基于半监督学习的二阶段页岩气井积液检测模型}
本研究提出了一种基于半监督学习的二阶段页岩气井积液检测模型，旨在克服数据标注稀缺的挑战，
同时充分利用数据的深层特征，实现积液的精准识别与分级。
模型分为两个阶段，其中第二阶段模型采用了半监督学习策略。

在第一阶段，本研究构建了一种基于长短期记忆网络（LSTM）的自编码器模型，
专门用于识别井筒是否发生积液。模型能够自主学习正常井筒数据的特征模式，
从而建立对正常状态理解。在此基础上，研究引入动态阈值机制，
利用模型对异常数据的重构误差来区分积液数据与正常数据。

第二阶段，设计了融合双注意力增强机制的特征提取模块，
并将提取的特征图输入到多随机卷积核变换网络（MultiRocket）中进行特征提取，
提取出的特征值输入到多层感知机网络（MLP）中实现最终的积液分级。
双注意力机制包括块间意力和块内注意力，可动态调整特征重要性，增强关键信息捕捉能力。
MultiRocket作为一种高效、灵活的特征提取与分类算法，在高维数据分类任务中表现出色。
二者结合优化特征表示，显著提升模型泛化能力和分类精度。

\subsection{数据清洗}
在实际的数据收集过程中，由于设备故障、传输不稳定或人为操作等问题，数据中可能会出现异常值或缺失值。
数据清洗的作用在于提升数据质量，去除错误、重复或无关的信息，填补缺失值，修正异常值，
从而确保数据的准确性、完整性和一致性，为后续分析和建模提供可靠的基础。

\subsubsection{异常值处理}
本研究采用3-sigma法则来识别数据集中的异常值，该方法依赖于数据集的标准差和平均值。
基于正态分布的性质，其中大约99.7\%的数据落在平均值的三个标准差之内。
3-sigma法则中的上、下限的计算公式如下：
\begin{equation}  \label{eq:3-1}
	\text{上限}=\mu+3\sigma
\end{equation}
\begin{equation}  \label{eq:3-2}
	\text{下限}=\mu-3\sigma
\end{equation}
其中，\(\mu\)表示计算数据的平均值，\(\sigma\)表示计算数据的标准差。

\subsubsection{缺失值处理}
缺失值填补方面，为了保持数据整体的时间结构，任何连续缺失值超过30分钟的数据段都将被丢弃。
对于连续缺失值小于30分钟的数据段，采用三次样条差值进行填充。
如果缺失值不是连续的，则使用先后的平均值来填充。三次样条差值的公式如下：
\begin{equation}  \label{eq:3-3}
	C(x) =
	\begin{cases}
	C^0(x) & \text{if } x < x^0 \\
	C^i(x) & \text{if } x^i \leq x < x^{i+1} \\
	C^{n}(x) & \text{if } x > x^{n}
	\end{cases}
\end{equation}
\begin{align}  \label{eq:3-4}
	C^i(x) = a^i_3(x - x^i)^3 + a^i_2(x - x^i)^2 + a^i_1(x - x^i) + a^i_0 \\
	\text{for } i = 0, 1, 2, \ldots, n-1(m-1) \nonumber
\end{align}
其中，\(C^i(x)\)表示三次样条插值函数，\(n\)表示数据段的区间总数，\(a\)表示三次样条插值中的插值系数。

\subsubsection{噪声处理}
由于测量误差或外部干扰，数据中存在很多噪声信息。
平滑处理可以减少噪声的影响，使数据更清晰，便于建模。
本研究采用快速傅里叶变换和局部加权散点图平滑法（LOWESS）\cite{69}相结合的平滑方法。
具体来说，快速傅里叶变换将时域数据转换为频域数据，其公式如下：
\begin{equation}  \label{eq:3-5}
	X[k]=\sum_{n=0}^{N-1} x[n] e^{-j \frac{2 \pi}{N} k n}
\end{equation}
其中，\(X[k]\)表示频域数据，\(x[n]\)为时域数据。变换后，删除频率低于阈值\(k_0\)的分量：
\begin{equation}  \label{eq:3-6}
	X^{\prime}[k]=
	\begin{cases}
	X[k] & \text { if }|k| \geq k_{0} \\
	0 & \text { if }|k|<k_{0}
    \end{cases}
\end{equation}
然后通过反向快速傅里叶变换将频域数据换回时域数据:
\begin{equation}  \label{eq:3-7}
	x'[n]= \frac{1}{N} \sum_{n=0}^{N-1} X'[k]  e^{j\frac{2\pi}{N}kn}
\end{equation}

\begin{figure}[h]
	\centering
	\includegraphics[width=0.7\linewidth]{fig/chapter3/图3-1.pdf}
	\caption{平滑前后的一段动态生产数据}
	\label{fig:31}
\end{figure}

去噪后的时序数据通过LOWESS进一步平滑。
具体来说，对于每个数据点\(x_i\)，使用三次方权重函数计算与领域点\(x_j\)的权重\(\omega_{ij}\)：
\begin{equation}  \label{eq:3-8}
	\omega_{ij}=
	\begin{cases}
		(1-|d_{ij}|^{3})^{3} & \text { if } |d_{ij}|\leqslant1\\
		0 & \text { if }|d_{ij}|>1
	\end{cases}
\end{equation}
\begin{equation}  \label{eq:3-9}
	d_{ij}=\frac{x_j-x_i}{h}
\end{equation}
其中，\(h\)为带宽，用于控制平滑程度的参数，\(d_{ij}\)处于[-1, 1]范围内。
随后，使用权重\(\omega_{ij}\)来拟合平滑后数据点：
\begin{equation}  \label{eq:3-10}
	\hat{x}_i=\frac{\sum_j \omega_{ij} x_j}{\sum_j \omega_{ij}}
\end{equation}

图\ref{fig:31}展示了平滑前后的生产数据曲线，平滑前的数据呈现明显的噪声波动，
经过处理后，曲线变得更加平滑，有效滤除了部分高频噪声。
总体而言，数据清洗操作减少了噪声对分析结果的干扰，为后续的建模和分析奠定了坚实的基础。

\subsection{特征工程}
特征工程通过对原始数据进行选择、转换和优化，
提取出更具代表性和区分性的特征，从而提升模型的性能和泛化能力，降低过拟合风险。

\subsubsection{特征筛选}

采用递归特征消除与交叉验证方法（RFECV）\cite{71}来识别关键特征，

具体而言，AdaBoost模型最初使用所有特征进行训练，并计算每个特征的重要性得分，
然后利用交叉验证评估不同子特征集训练出的模型的性能。
重复上述步骤，直到达到所需数量的特征。

\subsubsection{特征降维}
选择特征后，数据仍然具有高维且复杂的结构，降维技术可以将数据投影到低维子空间中。
本研究采用核主成分分析（KPCA）方法\cite{71}对数据进行降维。
具体来说，这个过程从数据标准化开始，然后使用径向基函数（RBF）核来计算核矩阵:
\begin{equation}  \label{eq:3-11}
	K_{i j}=\exp \left(-\frac{\left\|x_{i}-x_{j}\right\|^{2}}{2 \sigma^{2}}\right)
\end{equation}
其中，\(K_{i j}\)表示样本\(i\)和\(j\)之间的相似度。
\(\sigma\)表示控制高斯分布宽度的RBF核参数。
接下来的步骤是计算每个样本的均值，从而得到均值向量:
\begin{equation}  \label{eq:3-12}
	m_{j}=\frac{1}{n} \sum^n_{i=1}K_{i j}
\end{equation}
其中，\(m_{j}\)表示第\(j\)个样本的均值。\(n\)表示样本总数。
然后，通过下面的公式得到中心核矩阵:
\begin{equation}  \label{eq:3-13}
	K^{\prime}=K-1 m^{T}-m 1^{T}+1 m^{T} 1
\end{equation}
其中，\(K^{\prime}\)表示中心核矩阵，1为全1矩阵。
最后，对中心特征矩阵进行特征值分解。
特征值越高的维度表示数据的方差越大，表明这些维度具有更强的描述能力，可以捕获更重要的结构。
相反，低特征值对应的维数通常表示噪声或冗余信息。
去除这些低特征值维度可以提高模型的鲁棒性。

\subsection{时间维度处理}
为了进一步提高积液检测准确性，将时间维度纳入建模是一种有效的策略。
时间维度反映了气井生产条件的动态变化，有利于识别数据中的趋势或周期性模式。
常用的处理时间维度的技术是滑动窗口切片。
该技术将数据划分为固定长度的切片，以帮助模型更有效地理解数据。
在每个数据片中，数据点的日期被转换为时间戳格式，然后将时间戳用作顺序排列的索引。
本研究采用步长为1的滑动窗口，有助于保存更多的数据信息，并防止未来的信息泄漏到当前时间。
此外，为了更好地处理特征变化带来的非平稳性，我们对每个数据片单独进行了标准化处理。
图\ref{fig:35}可视化了滑动窗口切片后的标准化正常数据片和异常数据片，
正常数据片中的数据点分布较为集中，呈现出较为紧凑的聚集状态；
而异常数据片中的异常点则明显脱离于正常数据点所在的区域，形成了独立的分布特征。
总体而言，以滑动窗口为样本单位的方法能够进一步增强异常数据与正常数据之间的区分性，
为后续的异常检测和分类提供了更为清晰的判别依据。

\subsection{标签制作}
在本研究中，为了更准确地反映数据片的动态特征并增强模型对异常变化的捕捉能力，我们采用了特定的标注方法：
每个数据片中的最后一个时间戳对应的数据标签被指定为整个数据片的标签，如图\ref{fig:35}所示。
这种方法的核心在于强调时间序列的最新状态，使得模型能够更加关注数据在最近时间点的变化情况，
从而提高对异常事件的敏感性。因为在实际应用中，异常事件往往发生在时间序列的近期阶段，
而这种标注方式能够确保模型在训练过程中充分学习到这些关键信息，
进而提升其对异常的检测能力和对数据动态变化的适应性。

\section{二阶段页岩气井积液检测模型}

本研究采用二阶段模型完成积液严重程度分级，其结构如图\ref{fig:36}所示。
第一阶段采用基于LSTM的自编码器来检测积液是否出现，
第二阶段采用基于半监督学习的组合神经网络对积液严重程度进行分级。
二阶段模型非常灵活，可以根据具体情况为每个阶段选择不同的算法。
此外，二阶段模型通常更具可解释性，因为每个阶段都专门用于特定的任务。

\begin{figure}[h]
	\centering
	\includegraphics[width=1 \linewidth]{fig/chapter3/图3-6.pdf}
	\caption{二阶段井筒积液分级模型整体结构}
	\label{fig:36}

具体来说，先将数据片的动态特征放入基于LSTM的自编码器网络进行重构。
如果重构后数据与原数据的误差大于动态阈值，则认为该数据片是积液数据片。
确定积液后，将该数据片的广播后静态特征与特征向量进行水平拼接，
经过线性变换后输入双注意力增强模块。
该模块将输入数据映射为特征图，并通过MultiROCKET网络提取特征图的特征值。
最后，将特征值输入一个MLP网络中进行积液严重程度分级。

\subsection{第一阶段模型}
第一阶段模型包含基于LSTM的自编码器和基于指数加权移动平均算法的动态阈值，
其中，自编码用于重构输入的动态特征，而动态阈值用于计算动态特征和重构后动态特征之间的差异，
并根据差异大小来界定输入样本是否为积液样本。

\subsubsection{基于LSTM的自编码器}
第一阶段模型为LSTM自编码器，包含了编码器和解码器。
编码器将输入的动态特征编码为低维度的特征向量，其目的是捕捉数据的长期依赖信息并去除冗余信息和噪声。
解码器将特征向量重构为输入的数据，其目标是尽可能地恢复原始数据。
该模型仅使用正常的数据片进行训练，并通过最小化均方误差来优化参数，其公式如下：

\begin{equation}  \label{eq:3-14}
	\text{MSE}=\frac{1}{n}\sum^n_{i=1}(x_i-\hat{x}_i)
\end{equation}
其中，\(x\)为原始输入，\(\hat{x}\)为自编码器重构的输出。

当一个标签未知的数据片的动态特征输入到训练好的LSTM自编码器时，
如果该数据片属于正常数据片，则重构误差较小。
相反，如果输入数据片为积液数据片，则重构误差较大。
如图\ref{fig:37}所示，积液数据片的总误差几乎是正常数据片的两倍。
因为模型是基于正常数据片训练出来的，所以无法很好地重构积液数据片。
因此，可以设定一个阈值将重构误差较大的数据片标记为积液数据片。

\subsubsection{基于指数加权移动平均算法的动态阈值}
我们采用了指数加权移动平均（EWMA）算法来设置动态阈值。
该方法是一种加权平均的计算方法，其中最近的观测值权重较高，历史观测值权重逐渐减小。
在模型收敛过程中，第\(t\)轮验证集重构误差的平均值记为\(e_t\)，
然后更新当前轮的均值\(\mu_t\)和方差\(\sigma^2_t\):

\begin{equation}  \label{eq:3-15}
	\mu_t = \alpha \cdot e_t + (1-\alpha) \cdot \mu_{t-1}
\end{equation}
\begin{equation}  \label{eq:3-16}
	\sigma^2_t = \alpha \cdot (e_t-\mu_t)^2 + (1-\alpha) \cdot \sigma^2_{t-1}
\end{equation}
其中，\(\alpha\)为平滑因子，用于控制对新数据的敏感性。
\(\mu_{t-1}\)和\(\sigma^2_{t-1}\)为上一轮的均值和方差。
更新后，基于当前的均值和标准差设置阈值：

\begin{equation}  \label{eq:3-17}
	\text{T} = \mu_t + \beta \cdot \sigma_t
\end{equation}
其中，T代表阈值，\(\beta\)是一个可调参数，决定了阈值的敏感性。

\subsection{第二阶段模型}
第二阶段模型是一个组合神经网络，包含了双注意力增强模块、MultiROCKET网络和MLP网络。
其中，双注意力增强模块是本研究提出的一种用于增强数据表征能力的模块。
此外，我们采用了半监督学习来训练整个组合神经网络。

\subsubsection{双注意力增强模块}
对于第一阶段模型确定积液后的样本，其广播后静态特征与特征向量进行水平拼接，
然后通过一个线性层再输入到双注意力增强模块。
输入的数据被分成\(k\)块，每个块的长度为\(l\)。
块间和块内数据段分开排列并通过一个共享的线性层来完成线性变换。
然后，计算块间和块内数据段的注意矩阵，公式如下:

\begin{equation}  \label{eq:3-18}
	A = \text{softmax}(XL(X)^T)
\end{equation}
其中，\(A\)表示注意力矩阵，\(X\)表示数据段，\(L\)表示共享线性层，\(T\)表示转置矩阵。
块间注意力矩阵的大小为\((k*k*l)\)，其中\((k*k)\)表示\(k\)个块成对之间的注意力权重，
\(l\)表示每个块中的数据条数。
随后，使用一个尺寸为\((1*1)\)、步幅为1的卷积核将第三个维度从\(l\)降为\(1\)。
接着，使用一个尺寸为1、步幅为1的卷积核将\((k*k)\)的矩阵降为长度为\(k\)的向量，
代表\(k\)个块内注意力矩阵的比例因子，表示为\(\alpha\)。

\begin{figure}[h]
	\centering
	\includegraphics[width=0.6 \linewidth]{fig/chapter3/图3-8.pdf}
	\caption{正常数据和积液数据通过双注意力增强模型后的特征图（块数为2）}
	\label{fig:38}
\end{figure}

块内注意力矩阵的大小为\((l*l*k)\)，其中\((l*l)\)表示块内\(l\)条数据成对之间的注意力权重，
\(k\)表示块的数量。首先，将块内注意矩阵乘以前面的求得的比例因子\(\alpha\)来调整数值大小。
然后，对于每个块内注意力矩阵，使用\(\lfloor \frac{l}{k} \rfloor\)个尺寸为1、
步幅为1的卷积核将\((l*l)\)的矩阵降维\((l*\lfloor \frac{l}{k} \rfloor)\)的矩阵。
随后，将\(k\)个块内注意力矩阵按水平拼接并填充，得到一个\((l*l)\)的特征图。
图\ref{fig:38}对特征图可视化，正常数据的特征图表现为分散的注意模式，
而积液数据的特征图表现为集中的注意模式，表明该特征提取模块可以进一步放大两者的差异。

\subsubsection{多随机卷积核变换网络}
多随机卷积核变换网络（MultiRocket）是一种用于时间序列分类的高效特征提取方法，
其计算过程基于卷积操作和特征池化，旨在通过随机生成的卷积核快速提取时间序列的关键特征。
首先，MultiRocket通过随机生成卷积核来提取特征。每个卷积核的权重由两部分组成：
\(\alpha\)权重值为-1，用于捕捉局部差异；\(\beta\)权重值为2，用于捕捉局部相似性。
卷积核的权重通过组合不同的位置索引生成，例如，使用长度为9的卷积核，其中包含6个-1和3个2。
然后，对于输入的时间序列数据，MultiRocket执行一维卷积操作，
并通过膨胀操作扩展卷积核的感受野，同时通过填充保持时间序列的长度。
随后将生成的卷积核应用于时间序列，通过加法操作模拟卷积过程。

MultiRocket通过多种方式来提取时序数据中的特征，
如正比例特征（PPV）：计算卷积结果大于某个偏置值的比例；
正值均值（MPV）：计算卷积结果中正值的均值；
正值位置均值（MIPV）：计算正值在时间序列中的位置均值；
最长正值延伸（LSPV）：计算最长连续正值的长度。
其计算公式如下\cite{73}：
\begin{equation}  \label{eq:3-19}
	\text{PPV}(Z)=\frac{1}{n}\sum^n_{i=1}[z_i>0]
\end{equation}
\begin{equation}  \label{eq:3-20}
	\text{MPV}(Z)=\frac{1}{m}\sum^m_{i=m}[z^+_i]
\end{equation}
\begin{equation}  \label{eq:3-21}
	\text{MIPV}(Z)=
	\begin{cases}
		\frac{1}{m}\sum^m_{j=1}i^+_j & \text{if } m>0 \\
		-1 & \text{if } m<=0
	\end{cases}
\end{equation}
\begin{equation}  \label{eq:3-22}
	\text{LSPV}(Z)=\max \left[j-i \mid \forall_{i \leq k \leq j} \text{ } z_{k}>0\right]
\end{equation}
其中，\(z\)为特征图每列一阶差分后的数据，\(z^+\)为\(z\)中的正值，
\(i^+\)为\(z^+_i\)在\(z\)中的位置，
\([j-i]\)表示\(z\)中第一个与最后一个正值位置之间的距离。

本研究中，MultiRocket将经过双注意力增强模块得到的特征图的每列及其一阶差分作为输入，
并使用随机卷积核来提取特征图中每一列数据的特征值。
输出的特征值包括正值比例（PPV）、正值均值（MPV）、正值位置均值（MIPV）和最长正值延伸（LSPV），
最终得到长度为\((4*2*l)\)的特征值向量。其中，4表示4种不同的特征值，2表示输入数据及其一阶差分，
\(l\)表示特征图的总列数。最后，将特征值向量输入一个三层MLP网络完成积液严重程度分级。

\subsubsection{半监督训练流程}
为了在少量标签数据的情况下提高模型性能，第二阶段模型训练程中采用了半监督训练策略。
图\ref{fig:39}显示了半监督学习的各个阶段。
首先，利用标签数据训练一个初始模型开始，并应用训练后的模型来预测无标签数据。
在分类任务中，该模型最终输出每个类别的概率。
我们手动设置了一个阈值，当一个特定类别的概率超过这个阈值时，该类别将被用作一个伪标签。
将标签数据集与伪标签数据集合并，形成一个扩展的训练数据集，并用于模型的再训练。
重复这些步骤，直到所有生成的伪标签数据对应的概率都超过该阈值。
在本研究中，考虑到无标签数据量远大于标签数据量，概率阈值被设置为0.99。

\subsection{评价指标}
第一阶段模型效果通过接收者操作特征曲线（ROC）和曲线下面积（AUC）来评价。
ROC曲线的x轴表示假正率（FPR）， y轴表示真正率（TPR），也称为灵敏度或召回率。
AUC的范围从0到1，AUC为1表示理想状态，AUC为0.5表示模型性能等同于随机猜测，低于0.5表明模型性能较差。

第二阶段模型效果通过正预测值（PPV），负预测值（FOR），假发现率（FDR），负预测值（NPV），
真阳性率（TPR），假正率（FPR），假负率（FNR），真负率（TNR），正类似然比（LR+），
负类似然比（LR-），准确率（ACC）和F1得分来评价。

\subsubsection{二阶段模型整体实验结果}

\subsubsection{与物理模型的对比}
为了进一步验证所提模型对积液检测的及时性，
我们在数据集A所在的开采区随机抽样了几口积液气井来搭建Droplet Removal和Film Reversal物理模型，
并与我们的模型比较第一次检测出积液的时间点。
图\ref{fig:312}显示了不同模型在自喷井上的积液预警时间。
当液体装载量超过临界阈值时，套管压力迅速增加，有利于早期井筒积液检测。
而随着积液严重程度的增加，套管压力增长幅度逐渐减缓。
例如，在2023年4月5日之后，A井的套管压力波动减小，
而在2023年3月20日之后，B井的套管压力也表现出类似的情况。
这种渐进式增加会妨碍物理模型检测井筒积液的及时性。

图\ref{fig:314}显示了不同模型在柱塞井上的积液预警时间，二阶段模型对轻度积液更为敏感。
例如，2023年3月6日，由于油管压力和套管压力的差值大幅增加，
物理模型和二阶段模型都能够快速确定E井出现井筒积液。
然而，在2023年3月16日，由于F井中油管压力和套管压力的差值呈现出渐进式增长模式，
二阶段模型比物理模型更早地发现了井筒积液。
这是由于Droplet Removal模型和Film Reversal模型通过液体和气体的流动特性和相互作用来检查积液。
在井筒环境中，液体的流速往往远低于气体，这一特性在气井产水量减少时尤为显著。
随着井筒内液体的逐渐积累，它们开始对气体的流动形成阻碍，导致井筒内外的压力差显著增大。
由于液体所产生的阻力远大于气体，气体必须克服更大的压力差才能从井口顺利流出。
当井筒内的液体积累达到一定程度，压差就会发生迅速的变化，如E井所示。
然而，如果液体的积累速率是渐进的，气体虽然会受到一定影响，但仍能在一定程度上维持其流动。
此时，压力差的变化将呈现出更为温和的渐进式特征，如F井所示。
物理模型难以根据压力差的细微变化来准确判断井筒内是否存在积液，尤其是在轻度积液时。

\section{本章小结}
在本章中，首先详细介绍了本研究所使用的数据集及数据预处理过程，
包括数据清洗、特征维度处理、时间维度处理和标签制作。

然后，本章重点介绍了二阶段井筒积液分级模型，第一阶段模型为LSTM自编码器，
通过重构样本误差和动态阈值算法来区分正常数据片和积液数据片。
第二阶段模型为双注意力模块、MultiRocket网络和MLP网络的组合神经网络，
双注意力模块将输入的数据片映射为特征图，MultiRocket网络提取出特征图中的特征值，
MLP网络根据特征值来区分积液严重程度。

最后，本章通过一系列实验来验证模型的有效性，
二阶段井筒积液分级模型的总体准确率优于其他主流机器学习模型，
在三个数据集上的平均F1得分到达了0.84。
其次，及时性也优于主流的物理检测模型，总体积液预警时间提前了1到3天。
此外，我们还设计了消融实验来验证关键组件对模型检测性能的影响。
